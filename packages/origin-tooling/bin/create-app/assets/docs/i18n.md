# i18n

Bu uygulama `--i18n` ile üretildi. i18n bir eklentidir: istenmezse hiç üretilmez, istenirse
aşağıdaki dosyalarda toplanır ve tek seferde sökülebilir (bkz. **Kaldırma**).

## URL modeli

**Varsayılan dil öneksizdir**, diğerleri öneklidir:

```
/catalog        → 200   varsayılan dil (yönlendirme yok)
/en/catalog     → 200   İngilizce (route tablosu /catalog'u eşler)
/tr/catalog     → 308 → /catalog   (aynı sayfanın ikinci adresi olmaz)
/xx/catalog     → 404   (bilinmeyen dil)
```

Bunun iki sonucu var: ikinci dili eklemek **tek bir mevcut URL'i taşımaz** (linkler, sıralamalar ve
paylaşılmış adresler yerinde kalır) ve en çok istek alan sayfalar önlerinde bir yönlendirme olmadan
cevap verir.

**Accept-Language yönlendirmesi bilinçli olarak yoktur.** Ziyaretçiyi tarayıcı diline göre başka bir
adrese göndermek, canonical URL'in ziyaretçiye göre farklı cevap vermesi demektir: cache'lenemez ve
yanlış dilin indexlenmesinin bilinen yoludur. Dil değiştirme, header'daki switcher ile yapılır.

Route tablosu dilden habersizdir. `src/routing/rules.ts` içindeki `localePrefixes` rewrite'ları
öneki route eşleşmesinden önce soyar; tarayıcıdaki yol (`publicPath`) önekli kalır — canonical,
hreflang ve cache key onu kullanır.

## Parçalar

| Dosya                                         | Sorumluluk                                                     |
| --------------------------------------------- | -------------------------------------------------------------- |
| `src/lib/i18n/config.ts`                      | Dil listesi, varsayılan dil, yol ayrıştırma, hreflang üretimi  |
| `src/lib/i18n/messages.ts`                    | Tipli mesaj kataloğu ve `t(locale, key)`                       |
| `server/middleware/locale.ts`                 | Dil kararı, cookie hatırlama, öneksiz yolların yönlendirilmesi |
| `src/routing/rules.ts` → `localePrefixes`     | Önek soyan rewrite'lar                                         |
| `src/components/layout/language-switcher.tsx` | Dil değiştirici (düz link, JS gerektirmez)                     |
| `server/product/document-shell.ts`            | `<html lang>` ve sayfa başına hreflang alternatifleri          |
| `server/seo.ts`                               | Her dil için sitemap girdisi                                   |
| `src/lib/cache-keys.ts`                       | Cache key'inde dil boyutu                                      |

## Dil kararı

Sıra: **yoldaki önek** varsa o dil; yoksa varsayılan dil. Tahmin yok, cookie yok.

Middleware kararı `values: { locale }` olarak yayımlar. Bu iki şeyi aynı anda sağlar: loader'lar,
cache resolver'ı ve document shell aynı değeri okur; ve değer **paylaşımlı HTML cache key'ini
otomatik olarak böler** — bir ziyaretçinin Türkçe sayfası diğerine servis edilemez. Bu bölme
platformun `values` sözleşmesinden gelir, ayrıca elle yazılmaz.

## Yeni dil ekleme

1. `src/lib/i18n/config.ts` → `LOCALES` dizisine ekleyin.
2. `src/lib/i18n/messages.ts` → aynı anahtar kümesiyle kataloğu ekleyin (eksik anahtar derlenmez).
3. `src/routing/rules.ts` → `localePrefixes` listesine `{ source: "/<dil>/:path*", destination: "/:path*" }`.
4. `pnpm ci`.

Cache maliyetini unutmayın: her dil, cache'lenen her sayfanın entry sayısını bir kat artırır.

## Metin çevirme

Chrome metinleri katalogdadır:

```ts
import { t } from "~/lib/i18n/messages";
import { pageLocale } from "~/lib/i18n/config";

// Route loader'ında
loader: async (ctx) => ({ data: { locale: pageLocale(ctx) } }),
// Bileşende
<h1>{t(data.locale, "skipToContent")}</h1>
```

İçerik (ürün adı, makale, fiyat) katalogda değildir: onu gateway zaten çevrilmiş döndürmelidir.
Servis çağrılarına dili geçirin ve upstream'in dil başına cevap verdiğinden emin olun — aksi halde
cache key dile göre bölünürken içerik aynı kalır.

## SEO

- `<html lang>` her istekte çözülür.
- Her sayfa kendi hreflang kümesini taşır: tüm diller + `x-default`. Tek taraflı bir küme, hiç
  olmamasından kötüdür — arama motoru çevirileri birbirinin rakibi sayar.
- Sitemap her dili ayrı girdi olarak listeler.
- Canonical önekli yoldan üretilir; dil seçimi canonical'ı değiştirmez.

## Kaldırma

Eklenti olarak tasarlandığı için sökme adımları kesindir:

1. Şu dosyaları silin: `src/lib/i18n/`, `server/middleware/locale.ts`,
   `src/components/layout/language-switcher.tsx`, `tests/i18n.test.ts`, `docs/i18n.md`,
   `.claude/skills/i18n/`.
2. `server/middleware/index.ts` → `localeMiddleware` importunu ve liste satırını silin.
3. `src/routing/rules.ts` → `localePrefixes` bloğunu ve `rewrites` içindeki `...localePrefixes`
   satırını silin.
4. `src/lib/cache-keys.ts` → `pageLocale` importunu ve key parçalarını çıkarın (ya da tek dilli
   sabit bir değerle değiştirin).
5. `server/product/document-shell.ts` → `htmlLang` alanını sabit bir dile döndürün ve
   `languageAlternates` sarmalayıcısını kaldırın.
6. `server/seo.ts` → sitemap girdilerini dil döngüsünden çıkarın.
7. `src/components/layout/root-layout.tsx` → `LanguageSwitcher` kullanımını silin.
8. Yayında olan bir site için: kaldırılan dillerin önekli URL'leri hâlâ index'te ve linklerde
   olacaktır. `redirects` içine `{ source: "/en/:path*", destination: "/:path*", status: 308 }`
   ekleyin. Varsayılan dil zaten öneksiz olduğu için o taraf değişmez.
9. `pnpm ci`.
