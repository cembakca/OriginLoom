# 0.7.21 — Client telemetry import migration düzeltmesi

## Sorun

`0.7.18-dev-experience-source-patches` migration'ındaki çok satırlı import eşleşmesi,
`src/entry.client.tsx` içinde analytics import'u telemetry import'undan önce geliyorsa
`logPageRequestIdInDev` binding'ini yanlışlıkla şu modüle ekleyebiliyordu:

```ts
@originloom/shared/lib/analytics/data-layer
```

Fonksiyon `@originloom/shared` paketinden kaldırılmadı. Doğru export yolu şudur:

```ts
@originloom/shared/lib/client/error-telemetry
```

## Otomatik (`origin-migrate`)

`0.7.21-client-entry-telemetry-import-fix` migration'ı:

1. Yanlış analytics import'undaki `logPageRequestIdInDev` binding'ini kaldırır.
2. Binding'i `client/error-telemetry` import'una ekler.
3. Daha önce kaldırılmışsa `logPageRequestIdInDev()` çağrısını yeniden ekler.

Patch yalnız bilinen bozuk kalıba dokunur ve idempotent'tir.

```bash
pnpm origin:migrate
pnpm origin:migrate --apply
pnpm install
pnpm build
```
