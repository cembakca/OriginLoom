# 0.5.28: performans kabulü, payload bütçeleri ve profiling

Tür: geriye uyumlu core telemetry ve React template tooling geliştirmesi. Otomatik uygulama
migration'ı yoktur.

Yeni React projeleri şu performans katmanlarını içerir:

- SSR document render ve gateway JSON parse histogramları;
- sıkıştırılmamış HTML ile island props hard budget'ları;
- source-control edilen performans politikası;
- açıkça kabul edilen, makine/profil uyumluluğu doğrulanan kapasite baseline'ı;
- knee sonrası ayrı Node process'inde CPU ve heap allocation profiling.

Yeni komutlar:

```bash
pnpm performance:compare
pnpm performance:accept
pnpm capacity:profile
pnpm capacity -- --profile-on-knee
```

Mevcut projeler paketleri birlikte yükseltebilir:

```bash
pnpm update "@originloom/*" --latest
pnpm test
pnpm build
```

Core metrics endpoint'i geriye uyumlu olarak şu serileri ekler:

- `ssr_serialization_duration_milliseconds`
- `ssr_payload_size_bytes`

Generator mevcut proje dosyalarını değiştirmez. Yeni performans akışını taşımak için yeni oluşturulmuş
React projedeki `load-test/`, `performance-policy.json` ve `docs/performance-acceptance.md` dosyalarını
referans alın. Kabul edilmiş `performance-baseline.json` source control'e alınmalıdır; ham
`load-test/reports/` çıktıları gitignore'da kalır.

Profiler açıkken üretilen RPS ve latency değerlerini normal kapasite baseline'ına almayın. CPU ve heap
profilleri yalnız teşhis içindir.
