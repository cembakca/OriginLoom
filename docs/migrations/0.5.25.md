# 0.5.25: stateful gateway contract scenarios

Tür: geriye uyumlu tooling capability. Otomatik uygulama migration'ı yoktur.

Manifest v2 artık request body fixture/schema doğrulaması, endpoint bazlı sabit veya environment
kaynaklı header, request body JSON Pointer environment binding'i, negatif HTTP status senaryoları ve
gövdesiz response beklentilerini destekler. Staging kontrolü gerçek HTTP request'ini bu tanımdan
üretir ve secret değerlerini rapora yazmaz.

Manifest v1 ve 0.5.24 manifest v2 dosyaları değişmeden çalışmaya devam eder. Mevcut projeyi yükseltmek
için fixed paket grubunu birlikte güncellemek yeterlidir:

```bash
pnpm update "@originloom/*" --latest
pnpm contracts:fixtures
```

Yeni yetenekleri kullanmak için oluşturulan bir projenin `docs/contracts.md` dosyasındaki request
body/header ve hata senaryosu örneklerini izleyin. Secret değerlerini manifest veya fixture'a
yazmayın; yalnız `CONTRACT_*` environment değişkeni adını kaydedin. `Authorization` ve `Cookie`
header'larını doğrudan tanımlamak yerine auth profili kullanın.
