# 0.7.11 — create-app plugin metadata (schema v2)

## Özet

`.originloom/project.json` şeması **v2** oldu. Üretilen projeler hangi `origin-create-app`
eklentilerinin etkin olduğunu `plugins: string[]` alanında kaydeder.

## Otomatik (origin-migrate)

- `schemaVersion`: `1` → `2`
- `plugins`: yoksa eklenir
  - `package.json` içinde `compose:up` script'i varsa → `["with-ops"]`
  - aksi halde → `[]`

Machine-owned dosyalar dışında route/component kaynakları değişmez.

## Manuel adım gerekmez

Mevcut uygulamalar upgrade sonrası aynı davranışı sürdürür. Yalnızca metadata kaydı
netleşir; doctor bilinmeyen eklenti id'lerini uyarır.

Bugün kayıtlı tek eklenti `with-ops` (`--with-ops`). Yeni eklenti genişletmesi donduruldu;
ayrıntı [plugin-mechanism.md](../plugin-mechanism.md).
