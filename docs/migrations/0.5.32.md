# 0.5.32: generated telemetry type düzeltmesi

Tür: `0.5.31` React template derleme düzeltmesi.

Web Vitals dynamic import hata kaynağı bounded client telemetry kontratına eklendi ve
`requestIdleCallback` feature detection'i DOM tiplerinden bağımsız, fallback'i erişilebilir bir
şekle getirildi. `0.5.31` ile proje oluşturduysanız doğrudan `0.5.32` paket/template sürümünü kullanın.

```bash
pnpm update "@originloom/*" --latest
pnpm typecheck
pnpm build
```
