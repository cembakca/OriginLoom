# 0.5.22: görünür Lighthouse raporları

Tür: tooling kalite raporu iyileştirmesi. Uygulama kaynakları için migration gerekmez.

`pnpm lighthouse` artık her ölçüm için `.lighthouseci/reports` altında hem JSON hem HTML rapor
üretir ve HTML dosyalarının tam yollarını komut sonunda gösterir. Kalite gateway ve metrics portları
boş portlardan seçilir; uygulama portu doluysa başka bir süreci ölçmek yerine komut açıkça başarısız
olur.

Mevcut proje yalnız fixed paket grubunu `0.5.22` sürümüne yükseltmelidir:

```bash
pnpm update "@originloom/*" --latest
pnpm lighthouse
```

Raporu macOS'ta örneğin şu şekilde açabilirsiniz:

```bash
open .lighthouseci/reports/home-1.html
```
