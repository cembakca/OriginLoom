# 0.5.35: CSP cache nonce ve route-aware build özeti

Tür: güvenlik düzeltmesi ve build görünürlüğü.

- Shared HTML ve fragment cache artık request'e özel CSP nonce saklamaz. Cache-safe marker her
  response'ta o isteğin nonce değeriyle değiştirilir.
- Eski concrete nonce taşıyan Redis HTML kayıtları miss kabul edilerek güvenli biçimde yeniden
  doldurulur.
- `origin-build`, uygulamanın gerçek `server/routes/index.ts` registry'sini ve routing rules
  export'larını okuyarak route/cache özetini basar.
- Makine tarafından okunabilir sonuç `dist/originloom-manifest.json` içine yazılır.
- Annotate edilmemiş özel cache resolver'lar tahmin edilmez; `runtime-defined` olarak gösterilir.

Mevcut proje yalnız CSP düzeltmesini almak için paket grubunu yükseltip yeniden build/restart
etmelidir. Route'lar herhangi bir template listesine bağlı olmadan otomatik keşfedilir.

Cache TTL/SWR bilgisini build özetinde göstermek isteyen app-owned resolver'lar
`describeRouteCache(...)` kullanabilir. Generated React projelerde `pageCache(PageCacheId...)`
helper'ı runtime resolver ve build metadata'sını aynı registry tanımından üretir.

```bash
pnpm update "@originloom/*" --latest
pnpm origin:migrate --apply
pnpm install
pnpm build
pnpm ci
```

Özel route registry veya routing rules konumu kullanan projeler build ortamında sırasıyla
`ORIGIN_ROUTES_ENTRY` ve `ORIGIN_ROUTING_RULES` tanımlayabilir.
