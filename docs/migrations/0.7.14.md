# 0.7.14 — Public static dosyalar ve gateway scaffold

## Özet

- **`/public/*` servisi** — Proje kökündeki `public/` klasörü uygulama portundan servis edilir
  (`public/test.img` → `http://127.0.0.1:3010/public/test.img`). Platform `@originloom/core`
  içinde `createApp` mount'u; SSR/auth pipeline'ına girmez.
- **`origin-scaffold-gateway`** — Ham gateway cevabından fixture, OpenAPI şeması, manifest kaydı,
  TypeScript tipi ve `server/services/*` loader iskeleti üreten CLI.
- **`contracts:scaffold`** — Consumer contract'ı olan projelerde yeni script.

## Otomatik (`origin-migrate`)

| Migration id | Ne yapar |
| --- | --- |
| `0.7.14-public-static` | `public/README.md` ve `public/test.img` ekler (yoksa); `Dockerfile` runner'a `public/` COPY satırı ekler |
| `0.7.14-scaffold-gateway` | `contracts:fixtures` varsa `contracts:scaffold` → `origin-scaffold-gateway` script'ini ekler |

Standalone projede `@originloom/*` paketleri `^0.7.14` olur; `.originloom/project.json`
`templateVersion` güncellenir.

## Manuel adım (isteğe bağlı)

- **`docs/contracts.md`** — Scaffold bölümü yeni şablonda vardır; mevcut projede dokümantasyonu
  güncellemek isteğe bağlıdır (migration dosyayı ezmez).
- **`docs/runtime-performance.md`** — `/public/*` deadline muafiyeti notu; isteğe bağlı.
- **Showroom / contracts manifest'i olmayan projeler** — `public/` yeterlidir; `contracts:scaffold`
  script'i eklenmez.

## Tooling yükseltmesi

```bash
pnpm up @originloom/tooling@^0.7.14 @originloom/core@^0.7.14 @originloom/react@^0.7.14 @originloom/shared@^0.7.14
origin-migrate --apply
pnpm install
pnpm origin:doctor --strict
pnpm ci
```

Scaffold kullanımı:

```bash
cat response.json | pnpm contracts:scaffold -- --id my-endpoint --path /gateway/path
pnpm contracts:scaffold -- ... --apply
```

Public dosya doğrulama:

```bash
pnpm dev
curl -i http://127.0.0.1:3010/public/test.img
```
