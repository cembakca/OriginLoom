# 0.5.17: ESLint 10

Migration id: 0.5.17-eslint-10

Tür: generated geliştirme araçları güncellemesi. OriginLoom runtime API'sinde breaking change yoktur;
projenin desteklediği minimum Node.js patch sürümü 22.12'den 22.13'e çıkar.

## Otomatik değişiklikler

`origin-migrate --apply` yalnız `package.json` içindeki şu alanları günceller:

- `engines.node`: `>=22.13.0`
- `devDependencies.@eslint/js`: `^10.0.1`
- `devDependencies.eslint`: `^10.8.0`

Uygulama kaynakları, ESLint config'i ve kullanıcı kuralları değiştirilmez. Generated projeler zaten
flat config kullandığı için config dönüşümü gerekmez.

## Manuel kontrol

Özel ESLint plugin'i eklediyseniz plugin'in ESLint 10 peer desteğini doğrulayın. Desteklemeyen bir
plugin için peer override eklemeyin; plugin desteği çıkana kadar ESLint 9'da kalın.

## Doğrulama

```bash
pnpm origin:migrate
pnpm origin:migrate --apply
pnpm install
pnpm lint
pnpm typecheck
pnpm build
pnpm origin:doctor --strict
```

## Rollback

Migration öncesi `package.json`, `.originloom/backups/<kaynak>-to-0.5.17/package.json` altında
saklanır. Geri dönüşte bu dosyayı geri yükleyip `pnpm install` çalıştırın.
