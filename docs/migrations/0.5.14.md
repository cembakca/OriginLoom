# 0.5.14: upgrade contract v1

Migration id: 0.5.14-upgrade-contract-v1

Tür: geriye uyumlu platform/tooling özelliği. Runtime API breaking change içermez.

## Eklenenler

- .originloom/project.json template metadata'sı
- origin-doctor read-only uyumluluk kontrolü
- origin-migrate dry-run/apply migration runner'ı
- Generated docs/upgrading.md runbook'u
- Fixed-group drift ve pending migration CI kapısı

## 0.5.12 projesinden otomatik değişiklikler

- package.json içine origin:doctor ve origin:migrate script'leri eklenir.
- Standalone @originloom/* aralıkları hedef fixed-group sürümüne çekilir.
- .originloom/project.json oluşturulur.
- docs/upgrading.md yalnız mevcut değilse eklenir.
- Değiştirilen mevcut JSON dosyaları .originloom/backups altında korunur.

Route, component, config, gateway contract ve ürün dokümanı değiştirilmez.

## Doğrulama

```bash
pnpm origin:migrate
pnpm origin:migrate --apply
pnpm install
pnpm origin:doctor --strict
pnpm ci
```

İkinci origin:migrate çağrısı uygulanacak değişiklik olmadığını söylemelidir.
