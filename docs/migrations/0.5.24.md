# 0.5.24: gateway contract manifest v2

Tür: geriye uyumlu tooling ve React template capability. Otomatik uygulama migration'ı yoktur.

Yeni React projeleri request ve response beklentilerini ayıran manifest v2 üretir. Her senaryo sabit
bir `operationId`, request method/path ve response status/content-type/schema/fixture tanımı taşır.
Bearer auth profilleri secret değerini değil yalnız `CONTRACT_` prefix'li environment değişkeninin
adını saklar.

Manifest v1 dosyaları tooling içinde normalize edilerek çalışmaya devam eder. Mevcut projenin
`contracts/gateway-contracts.json` dosyası otomatik değiştirilmez; yalnız fixed paket grubunu
yükseltmek güvenlidir:

```bash
pnpm update "@originloom/*" --latest
pnpm contracts:fixtures
```

Manifest v2'ye manuel geçişte yeni bir proje çıktısındaki `docs/contracts.md` ve
`contracts/gateway-contracts.json` referans alınmalıdır. Auth secret'ları manifest veya fixture'a
yazılmamalıdır.
