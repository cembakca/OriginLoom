# 0.5.27: tek komutluk React kapasite testi

Tür: geriye uyumlu React template ve tooling geliştirmesi. Otomatik uygulama migration'ı yoktur.

Yeni React projeleri production build, uygulama ve mock gateway yaşam döngüsünü tek komutta yöneten
bir kapasite runner'ı içerir:

```bash
pnpm capacity:quick
pnpm capacity
```

Full profil bütün örnek route'ları kademeli bağlantı sayılarında ve üç tekrar halinde ölçer. Markdown
ve JSON raporları `load-test/reports/` altında oluşur. Ayrı cold-burst, stale single-flight, warm
data-cache ve cache'siz public API deneyleri gerçek mock-gateway çağrılarını sayarak cache korumasını
doğrular. Runner ile hedef aynı makinede olduğundan rapor uygulama ve load-generator CPU değerlerini
ayırır ve bu ölçümün production kapasite taahhüdü olmadığını belirtir.

Mevcut projeler paketleri güvenle birlikte yükseltebilir:

```bash
pnpm update "@originloom/*" --latest
pnpm test
pnpm build
```

Generator mevcut proje dosyalarını değiştirmez. Kapasite kurgusunu mevcut bir React projesine almak
isterseniz yeni üretilmiş projedeki şu dosyaları referans alın:

- `load-test/capacity.mjs`
- `load-test/capacity-metrics.mjs`
- `load-test/capacity-report.mjs`
- `load-test/capacity-scenarios.mjs`
- `docs/capacity.md`
- `mock-gateway/server.mjs` içindeki yalnız lokal sayaç endpoint'i

Ek olarak `autocannon` dev dependency'sini ve `capacity` / `capacity:quick` script'lerini taşıyın.
Rapor klasörünü source control dışında tutmak için `load-test/reports/` satırını `.gitignore`'a
ekleyin. Mock gateway sayaçları production server'a ait değildir.
