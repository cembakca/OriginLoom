# 0.5.21: gateway contract ve frontend kalite kapıları

Tür: template capability. Otomatik migration yoktur; oluşturulmuş projenin uygulama-owned contract,
CI, telemetry ve bütçe dosyaları overwrite edilmez.

## Yeni projeler

React template aşağıdaki parçaları hazır üretir:

- OpenAPI 3.1 consumer schema, checked-in fixture'lar ve local/staging contract komutları
- Scheduled staging contract workflow'u ve fixture/response drift raporu
- Island/chunk gzip bütçeleri, Lighthouse route eşikleri ve mevcut Playwright/Axe kapısı
- CLS, INP, LCP, island mount süresi ve client mount failure gözlemleri

## Mevcut projeye opt-in

`origin-migrate` bu dosyaları otomatik eklemez. Uygulamanın endpoint ve bundle yapısı ürüne özel
olduğu için yeni bir 0.5.21 React projesindeki aşağıdaki dosyaları referans alarak kontrollü taşıyın:

- `contracts/` ve `performance-budgets.json`
- `lighthouserc.json` ve `.github/workflows/contract-staging.yml`
- `docs/contracts.md` ve `docs/performance.md`
- `package.json` içindeki `contracts:*`, `budget:bundle`, `quality:server`, `lighthouse` script'leri
- client entry'deki `web-vitals` kaydı ve server API'deki `mountClientMetricApi` mount'u

Paket grubunu birlikte yükseltin ve React uygulamasına `web-vitals`, geliştirme bağımlılıklarına
`lighthouse` ekleyin. Uygulamadaki mevcut Axe testi korunmalıdır.

## Doğrulama

```bash
pnpm contracts:fixtures
pnpm build
pnpm budget:bundle
pnpm e2e
pnpm lighthouse
```

Staging erişimi varsa ayrıca:

```bash
CONTRACT_BASE_URL=https://staging-gateway.example.com pnpm contracts:staging
```

## Rollback

Eklenen script, config, contract ve telemetry mount'larını birlikte kaldırın; paketleri fixed group
olarak önceki sürüme döndürün. Uygulama-owned dosyalarda otomatik backup üretilmez, çünkü bu sürüm
otomatik migration çalıştırmaz.
