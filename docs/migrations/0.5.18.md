# 0.5.18: Vitest kapsamı

Migration id: 0.5.18-vitest-scope

Tür: generated test runner düzeltmesi. Runtime davranışı ve uygulama kaynakları değişmez.

## Otomatik değişiklik

`origin-migrate --apply`, `package.json` içindeki unit/integration test komutunu şu hale getirir:

```json
{
  "scripts": {
    "test": "vitest run tests"
  }
}
```

Böylece `e2e/*.spec.ts` dosyalarını yalnız Playwright çalıştırır; Vitest bunları ikinci kez toplamaya
çalışmaz.

## Doğrulama

```bash
pnpm test
pnpm e2e
pnpm ci
```

## Rollback

Migration öncesi `package.json`, `.originloom/backups/<kaynak>-to-0.5.18/package.json` altında
saklanır.
