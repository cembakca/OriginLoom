# 0.5.30: production sıcak-yol optimizasyonları

Tür: geriye uyumlu runtime performans sürümü. Otomatik uygulama migration'ı yoktur.

Bu sürüm ilk beş ürün-runtime iyileştirmesini platforma taşır:

- self-contained production SSR bundle Node 22 hedefiyle, isimleri koruyan minification kullanır;
- CSP policy ve sabit security header yapısı startup'ta bir kez hazırlanır;
- health, static asset ve açıkça tanımlı long-lived GET yolları gereksiz `Request`/`AbortSignal`
  allocation'ını atlar;
- URL normalization, routing, route match ve metric label request başına bir kez hazırlanır;
- fragment içermeyen HTML cache HIT/STALE yolu stitching/regex maliyetini atlar.

Redis cache wire format v2 fragment-presence metadata'sı ekler. Binary v1 ve legacy JSON kayıtları
okunmaya devam eder; rolling deployment sırasında cache flush gerekmez.

Mevcut projeler paketleri birlikte yükseltebilir:

```bash
pnpm update "@originloom/*" --latest
pnpm test
pnpm build
pnpm capacity:quick
```

`vite.server.config.ts` platform `createServerViteConfig` preset'ini kullanıyorsa bundle iyileştirmesi
otomatik gelir. Kendi server Vite build ayarlarınızı tamamen değiştirdiyseniz Node 22 target,
minification, readable stack/profile isimleri ve dist-only deployment beklentisini birlikte doğrulayın.

Generated projedeki yeni [runtime performansı](../../packages/origin-tooling/bin/create-app/assets/docs/runtime-performance.md)
dokümanı uygulama sahipliği sınırlarını ve operasyon kontrol listesini açıklar. Generator mevcut proje
dosyalarını değiştirmez; bu dokümanı isterseniz yeni oluşturulan bir `0.5.30` React projesinden alın.
