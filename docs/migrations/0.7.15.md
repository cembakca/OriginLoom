# 0.7.15 — Navigation paint ve view transitions

## Özet

Sayfa yenileme ve gezinmede siyah ekran flaşını azaltır:

- **`DocumentLayout` kritik paint** — `@originloom/react` head'e inline arka plan rengi,
  `color-scheme`, `theme-color` ve view-transition kuralı basar. Harici Tailwind CSS gelmeden
  önce canvas siyah/koyu kalmaz.
- **Cross-document View Transitions** — Aynı origin `<a href>` geçişlerinde (Chrome/Edge 126+)
  giden sayfa yeni HTML hazır olana kadar ekranda kalır.
- **`criticalPaint` renderer hook** — Marka rengine göre özelleştirilebilir.

Hard refresh (F5) tarayıcı eski dokümanı siler; bu sürüm o aralıktaki siyah flaşı giderir ve
link geçişlerini Next/Nuxt benzeri tutar.

## Otomatik (`origin-migrate`)

| Migration id | Ne yapar |
| --- | --- |
| `0.7.15-navigation-paint` | `src/styles/globals.css` dosyasına `@view-transition { navigation: auto; }` ekler (yoksa) |

Kritik paint platform paketinde gelir; uygulama kaynağı değişmez. `@originloom/react` yükseltmesi
yeterlidir.

## Manuel adım (isteğe bağlı)

Özel arka plan rengi için renderer'da:

```tsx
createReactRenderer({
  criticalPaint: {
    backgroundColor: "#ffffff",
    themeColor: "#ffffff",
  },
  // ...
});
```

`docs/links.md` view-transition notu yeni şablonda vardır; mevcut projede isteğe bağlı güncellenir.

## Tooling yükseltmesi

```bash
pnpm up @originloom/tooling@^0.7.15 @originloom/core@^0.7.15 \
  @originloom/react@^0.7.15 @originloom/shared@^0.7.15
pnpm origin:migrate --apply
pnpm install
pnpm origin:doctor --strict
pnpm ci
```

Doğrulama:

```bash
pnpm dev
# Link tıklama: giden sayfa kalır, sonra yeni sayfa gelir (Chrome 126+)
# F5: siyah flaş yerine slate-50 arka plan
```
