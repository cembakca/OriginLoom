# 0.6.0: Gateway-backed progressive streaming

Tür: geriye uyumlu minor özellik. Mevcut uygulamaların runtime davranışı kendiliğinden değişmez.

- Yeni React template'inde `/live` route'u artık 600 ms'lik route-local `setTimeout` üretmez.
- `server/services/live-message.ts`, gateway'deki `/live/message` çağrısını hemen başlatır; route bu
  non-critical Promise'i await etmeden React Suspense data'sına verir.
- Geç gelen payload byte bütçesi ve runtime schema guard'ından geçer. OpenAPI şeması, consumer
  contract manifesti ve fixture aynı kontratı doğrular.
- Local mock gateway yalnız `/live/message` endpoint'ini varsayılan 600 ms geciktirir. Bu fixture
  `MOCK_LIVE_MESSAGE_DELAY_MS` ile değiştirilebilir; production gateway'de yapay gecikme yoktur.
- `pnpm capacity` içindeki streaming latency artık yalnız renderer timer'ını değil gerçek
  app-to-gateway request sınırını da kapsar.

Mevcut projelerin app-owned route ve service dosyaları migration tarafından ezilmez. Aynı örneği
benimsemek isteyen projeler:

1. Gateway'e `{ "message": string }` döndüren bounded bir endpoint eklemeli.
2. Endpoint için OpenAPI/fixture/consumer contract ve runtime guard tanımlamalı.
3. Service Promise'ini loader data'sına await etmeden vermeli.
4. Değer redirect, status veya not-found kararını etkiliyorsa deferred yapmamalı; stream başlamadan
   await etmelidir.

Paket fixed group'u `0.6.0`'a yükseltilir:

```bash
pnpm add -D @originloom/tooling@0.6.0
pnpm origin:migrate
pnpm origin:migrate --apply
pnpm install
pnpm origin:doctor --strict
pnpm ci
```
