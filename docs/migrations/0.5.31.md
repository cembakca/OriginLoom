# 0.5.31: fragment, React ve shell sıcak-yol optimizasyonları

Tür: geriye uyumlu React runtime/template performans sürümü. Otomatik app migration'ı yoktur.

- Redis cache wire format v3, fragment marker adı ve offset planını taşır. v1, v2 ve legacy JSON
  kayıtları okunur; cache flush gerekmez.
- Cache hit fragment stitching regex yerine önceden derlenmiş offset planını kullanır.
- React fragment partial render static markup üretir; document davranışı değişmez.
- Generated React app global Query provider kullanmaz. Yalnız `account-panel` provider import eder.
- Props'suz island boş `data-props` attribute'u üretmez.
- Web Vitals ilk client chunk'ından ayrılıp load sonrası idle dynamic import'a taşınır.
- Menu cache hit'leri doğrulanmış immutable process snapshot'ını yeniden kullanır.

Mevcut projede global provider kullanıyorsanız `src/hydrate.client.tsx` içindeki `Wrapper` seçeneğini
kaldırın ve `AppQueryProvider`'ı yalnız query hook'u kullanan island component'inin içine taşıyın.
Provider global QueryClient singleton kullandığından query cache paylaşımı korunur.

```bash
pnpm update "@originloom/*" --latest
pnpm typecheck
pnpm test
pnpm build
pnpm budget:bundle
```

Generator mevcut app-owned dosyaları değiştirmez. Yeni örnek için `0.5.31` React template'indeki
`src/entry.client.tsx`, `src/hydrate.client.tsx`, `src/islands/account-panel.tsx` ve
`server/services/menu.ts` dosyalarını birlikte karşılaştırın.
