# 0.7.12 — Supply chain ve multi-PM scaffold

## Özet

- `origin-sbom` artık **pnpm**, **npm** ve **Yarn Berry** lockfile'larından CycloneDX 1.6 SBOM üretir.
- Yeni `origin-audit` komutu production audit'i package manager'a göre çalıştırır.
- `origin-create-app --package-manager pnpm|npm|yarn` ile lockfile, CI, Docker ve metadata PM'e göre üretilir.
- Platform monorepo: `pnpm run sbom`, `dependency-track.yml`, [supply-chain-platform.md](../supply-chain-platform.md).

Güvenlik dependency patch'leri **0.7.13** sürümündedir — bkz. [0.7.13.md](./0.7.13.md).

## Mevcut pnpm uygulamaları

Upgrade gerekmez. Metadata'da `packageManager` alanı yoksa doctor varsayılan olarak pnpm lockfile arar.

İsteğe bağlı: `.originloom/project.json` içine `"packageManager": "pnpm"` ekleyin (doctor uyumu için).

## Yeni npm/yarn scaffold

```bash
origin-create-app payments-web --package-manager npm
origin-create-app analytics-web --package-manager yarn
```

İlk kurulumdan sonra ilgili lockfile'ı commit'leyin (`package-lock.json` veya `yarn.lock`).

Yarn Classic desteklenmez; Berry (>=3) kullanın.

## Tooling yükseltmesi

```bash
pnpm up @originloom/tooling@^0.7.12 @originloom/core@^0.7.12 @originloom/react@^0.7.12 @originloom/shared@^0.7.12
```

Mevcut projelerde `package.json` script'lerine manuel eklenebilir:

```json
"audit:prod": "origin-audit"
```

(`sbom` script'leri zaten `origin-sbom` kullanıyorsa değişmez.)
