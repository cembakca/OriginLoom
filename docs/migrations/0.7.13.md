# 0.7.13 — Güvenlik dependency patch

## Özet

Platform ve `origin-create-app` şablonu için production audit kapısını yeşile çeken patch sürümü:

- **Hono `^4.12.34`** — CVE-2026-71850 (`hono/jsx` `memo()` SSR cross-request reuse) ve ilgili middleware düzeltmeleri.
- **Transitive audit pinleri** (`pnpm-workspace.yaml` / npm `overrides` / yarn `resolutions`):
  - `fast-uri@^3.1.5`
  - `xmlbuilder2>js-yaml@^4.3.1`
  - `nanoid@^3.3.18`
  - `postcss@^8.5.23`

OriginLoom SSR **`react-dom/server`** kullanır; `hono/jsx` `memo()` vektörü doğrudan uygulanmaz. Hono yine de HTTP katmanı ve scaffold tutarlılığı için yükseltilir.

## Otomatik (origin-migrate)

- `0.7.12-hono-ssr-security` — `package.json` içindeki `hono` alanını `^4.12.34` yapar (0.7.11 ve öncesinden gelen projeler).

Transitive override satırları machine-owned `pnpm-workspace.yaml` / npm `overrides` alanına **otomatik yazılmaz**; aşağıdaki manuel adımı uygulayın.

## Manuel adım (mevcut uygulamalar)

`pnpm-workspace.yaml` (veya npm/yarn eşdeğeri) içindeki `overrides` / `resolutions` bloğunu şablondaki pinlerle hizalayın. Referans: `packages/origin-tooling/bin/lib/package-manager.mjs` → `PNPM_DEPENDENCY_OVERRIDES`.

Ardından lockfile yenileyin ve audit doğrulayın:

```bash
pnpm install
pnpm audit:prod
```

## Tooling yükseltmesi

```bash
pnpm up @originloom/tooling@^0.7.13 @originloom/core@^0.7.13 @originloom/react@^0.7.13 @originloom/shared@^0.7.13
origin-migrate apply
pnpm install
```
