# 0.5.29: kapasite ve profiler güvenilirlik düzeltmeleri

Tür: geriye uyumlu React template tooling düzeltmesi. Otomatik uygulama migration'ı yoktur.

`0.5.28` performans kabul akışının gerçek tüketici provasında bulunan iki sınır düzeltilmiştir:

- Cache'siz public API 1:1 deneyi artık kapasite ölçümü gibi rate-limit'e yüklenmez; template'in
  public API güvenlik limitinin altında kontrollü 40 istek kullanır.
- CPU ve heap allocation profiling process başlangıcında değil, warm-up tamamlandıktan sonra Node
  inspector üzerinden başlar. Böylece startup/source-map allocation'ları workload teşhisini örtmez.

Ayrıca yalnız `full` profil ve en az üç tekrarlı, geçerli, CV sınırını aşmayan rapor performans
baseline'ı olarak kabul edilebilir. CLI reddi kısa ve anlaşılır hata mesajı verir.

Mevcut projeler paketleri birlikte yükseltebilir:

```bash
pnpm update "@originloom/*" --latest
pnpm test
pnpm build
```

Generator mevcut proje dosyalarını değiştirmez. `0.5.28` template'inden profiling veya kapasite
runner'ını kopyaladıysanız yeni oluşturulmuş projedeki `load-test/capacity.mjs`, `profile.mjs`,
`profile-target.mjs`, `performance.mjs` ve `performance-policy.mjs` dosyalarını birlikte güncelleyin.
