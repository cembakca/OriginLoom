# 0.5.26: cache'siz HTML içinde API data cache örneği

Tür: geriye uyumlu React template örneği. Otomatik uygulama migration'ı yoktur.

Yeni React projeleri `/data-cache` route'unu üretir. Route document cache kullanmaz; SSR her istekte
yeniden çalışırken `server/services/featured-items.ts`, doğrulanmış public gateway payload'ını ayrı
bir read-through cache'te saklar. Sayfa HTML render zamanı, gateway veri zamanı ve `MISS`, `FRESH`
veya `STALE` durumunu gösterir.

Mevcut projeler paketleri güvenle birlikte yükseltebilir:

```bash
pnpm update "@originloom/*" --latest
pnpm test
pnpm build
```

Generator mevcut proje dosyalarını değiştirmez. Örneği taşımak isterseniz yeni üretilmiş bir
projedeki şu dosyaları referans alın:

- `server/routes/data-cache.tsx`
- `server/services/featured-items.ts`
- `src/features/data-cache/data-cache-page.tsx`
- `tests/featured-items-cache.test.ts`
- `docs/caching.md`

`FEATURED_ITEMS_CACHE_TTL=10` ve `FEATURED_ITEMS_CACHE_SWR=30` öğretici örneğin hızlı gözlenmesi
içindir. Gerçek endpoint'te değerleri veri tazeliği SLO'suna göre belirleyin. Cache key'ine veya
payload'a cookie, authorization, session ya da kullanıcı kimliği eklemeyin.
