# 0.7.17 — Dev deneyimi ve client telemetri korelasyonu

## Özet

Geliştirme ve hata ayıklama akışını iyileştirir; production JSON log kontratı korunur.

- **Pretty dev logları** — `NODE_ENV=development` iken `LOG_FORMAT=pretty` (renkli, okunabilir).
  Test/staging/production JSON kalır.
- **Client → server hata korelasyonu** — SSR `pageRequestId` HTML'e gömülür; client hataları
  `/api/internal/client-errors` ile aynı id'yi taşır. Server log'da `page=` ile SSR satırı eşleşir.
- **SVG icon watch** — `pnpm dev` sırasında `src/assets/svg/` ve `.svgrrc.cjs` değişince otomatik
  `origin-generate-icons` çalışır.
- **SVGO sıkılaştırması** — `convertStyleToAttrs` Figma `style=""` export'larını `currentColor`
  dönüşümüne hazırlar.
- **Vite config** — şablonda `import.meta.dirname` (native config loader uyumu).

## Manuel adım (mevcut uygulamalar)

Yeni create-app projelerinde hepsi şablonda. Eski projede isteğe bağlı hizalama:

1. **`.svgrrc.cjs`** — `convertStyleToAttrs` plugin'i (`preset-default` sonrası):

   ```js
   { name: "convertStyleToAttrs" },
   { name: "convertColors", params: { currentColor: true } },
   ```

2. **`.env.development`** — explicit pretty log (core zaten dev'de default pretty):

   ```env
   LOG_FORMAT=pretty
   ```

3. **`src/entry.client.tsx`** — dev console'da page request id:

   ```ts
   import { logPageRequestIdInDev } from "@originloom/shared/lib/client/error-telemetry";
   logPageRequestIdInDev();
   ```

4. **`vite.config.ts` / `vitest.config.ts`** — `__dirname` yerine `import.meta.dirname`.
