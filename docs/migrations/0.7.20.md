# 0.7.20 — Hono 4.13 ve Node adapter 2.1

## Özet

Platform runtime'ı ve `origin-create-app` şablonu şu sürüm aralıklarına taşındı:

- `hono: ^4.13.3`
- `@hono/node-server: ^2.1.1`

Hono 4.13 sıkıştırma middleware'i `Vary: Accept-Encoding` başlığını kendisi eklediği için
OriginLoom core'daki aynı işi yapan uyumluluk wrapper'ı kaldırıldı. `serve`, `serveStatic`,
`getConnInfo`, route ve middleware kullanımlarında uygulama tarafında API değişikliği gerekmez.

## Otomatik (`origin-migrate`)

`0.7.20-hono-4.13` migration'ı mevcut `package.json` içinde bulunan iki dependency'yi günceller:

- `hono` alanı `^4.13.3`
- `@hono/node-server` alanı `^2.1.1`

Dependency uygulamada yoksa migration yeni bir alan eklemez. Migration idempotent'tir ve uygulama
kaynak dosyalarını değiştirmez.

## Uygulama

```bash
pnpm origin:migrate
pnpm origin:migrate --apply
pnpm install
pnpm origin:doctor --strict
pnpm ci
```

## Davranış doğrulaması

Dinamik olarak sıkıştırılan HTML yanıtlarında `Content-Encoding` ile birlikte
`Vary: Accept-Encoding` kalmaya devam eder. Sıkıştırılabilir bir temsil için istemci `identity`
seçse bile `Vary` artık yayımlanır; böylece ara cache'ler sıkıştırılmış ve sıkıştırılmamış
temsilleri aynı nesne olarak saklamaz. Precompressed statik asset seçimi değişmez.
