# 0.5.34: React kalite araçları dependency güvenliği

Tür: güvenlik ve release doğrulama sürümü.

- Autocannon 8'in `hyperid@3 → uuid@8` zinciri yalnız bu dependency kenarında API-uyumlu
  `hyperid@4` ile değiştirilir.
- Lighthouse 13.4.1'e yükseltilir; Lighthouse 12'nin Sentry/minimatch/brace-expansion güvenlik zinciri
  kaldırılır.
- React generated proje minimum Node sürümü `>=22.19.0` olur.
- Release provası düşük seviye dahil dependency audit, destek dışı UUID kontrolü ve gerçek kısa
  kapasite koşusu çalıştırır.

Mevcut React projesinde:

```bash
pnpm update "@originloom/*" --latest
pnpm origin:migrate --apply
pnpm install
pnpm audit --audit-level low
pnpm ci
```

Migration `package.json` içindeki Lighthouse ve Autocannon varlığını kontrol eder; yalnız ilgili kalite
araçları kuruluysa Node/Lighthouse/Hyperid alanlarını değiştirir. Temiz install sonrasında lockfile'da
`uuid@10` veya altı bulunmamalıdır.
